NLE Integration

Built for DaVinci Resolve Free 21.1+ and Studio

Seamless workflow across every DaVinci Resolve edition - including full Lua Bridge compatibility for Resolve Free 21.1+ and linked A/V clip preservation via FCP7 XML.

Resolve Free 21.1+ / 22+

Bridge Mode (Lua)

Blackmagic disabled external Python scripting and .drt exports in Free 21.1+. BadWords solves both automatically:

  1. Open your project in DaVinci Resolve.
  2. Click Workspace -> Scripts -> BadWords Bridge once per session.
  3. Launch BadWords from your Desktop or Start Menu - it connects and assembles linked FCP7 XML timelines automatically.

Resolve Studio (All Versions)

Native IPC or Embedded

Run BadWords as a standalone desktop window (enable Preferences -> System -> General -> External scripting: Local) or launch inside Resolve via Workspace -> Scripts -> BadWords.

Choose FCP7 XML (default, linked video + audio) or switch to Native .drt in Settings if you need to preserve Fusion comps, Color node grades, or Fairlight FX.

Resolve Free (21.0 & Older)

Embedded or Bridge

Launch directly via Workspace -> Scripts -> BadWords inside Resolve, or use BadWords Bridge for an independent desktop window. Both FCP7 XML and .drt assembly work cleanly.

Keep full control with color markers

AI is great at removing obvious dead air and stutters, but subtle comedic timing belongs to the editor. BadWords lets you auto-cut certain colors (e.g. Red fillers) while leaving Blue retakes or Green script deviations as native Resolve timeline markers.

  • Ctrl+Click any word in BadWords to jump the DaVinci Resolve playhead straight to that frame.
  • Optional 360p background video proxy renders complex Resolve timelines smoothly without fighting Whisper VRAM.
