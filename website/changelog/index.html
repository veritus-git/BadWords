Complete Release History (2026)

BadWords Changelog

Every major release from v1.0.0 to v4.1.2. All tags and binaries are archived on GitHub Releases.

v4.1.2 - macOS UX, Resolve Bridge & Search

2026-11-26
  • macOS Window & Fullscreen Polish: First launch opens maximized to the desktop; closing Settings from Fullscreen Spaces leaves zero ghost frames or black screens; popups drag smoothly on Retina.
  • DaVinci Resolve Bridge & .bws Import: Read-only Lua queries never switch active timelines; Native and Bridge timeline fingerprints match 1:1; .bws files bundle FCPXML fallback for Resolve Free 21.1+.
  • Chunked Marks & Faster Search: Manual color markings stay intact after live chunk streaming completes; precompiled Ctrl+F and Settings search; fixed in-app Update button.

v4.1.1 - Windows 11 Hardening & Transactional Updates

2026-11-25
  • Eliminated Win11 white taskbar preview rings/startup bars, added automatic BADWORDS_SAFE_BOOT=1 on GPU-less PCs, and deferred Resolve DLL loading until Resolve runs.
  • Fixed Windows Whisper symlink failure (WinError 1314), partial model cache validation, and transactional package replacement in the Rust installer.

v4.1.0 - Unified Scaling, Zero-Sudo Setup & 11 Languages

2026-11-25
  • True Auto OS DPI scaling (75%-200%) across Windows 11, Wayland/X11, and macOS Retina without double multiplication.
  • Zero-sudo portable Python 3.12 on Linux/macOS, static-CRT Windows binaries (no missing VCRUNTIME140.dll), redesigned 9-tab Settings, and 631 synced keys across all 11 languages.
  • Added hard end-of-timeline playback stops, audio muxing into 360p Resolve video proxies, and whitelist safe updates.

v4.0.1 & v4.0.0 - Standalone Workstation & Live Waveform

2026-11-06 - 2026-11-11
  • Full Standalone Mode (no Resolve required) with FCP7 XML, FCPXML, OTIO, and EDL export + 360p video proxies.
  • Interactive waveform timeline with real-time cut skipping, sub-5 ms RAM silence tuning, Apple Silicon MLX (~11x), marquee box selection, FCP7 XML default for Resolve Free 21.1+, and Rust GUI installer.

v3.2.4 & v3.2.3 - Engine Precision & WAV Assembly Hardening

2026-07-31
  • Fixed speech boundary offset alignment, word selection drift during audio preview seeking, and safe PCM decoding in WavAssemblyThread.

v3.2.2 - Pure Faster-Whisper Engine & 1.7x CPU Speedup

2026-07-30
  • Removed heavy stable-ts/PyTorch dependency, relying directly on faster-whisper for native word-level timestamps and lighter installs.
  • Made Ultra Precise (chunking) default and enabled cutting any selected marker color dynamically.

v3.2.0 - Built-in Audio Preview, .bws Saves & AutoSave

2026-07-27
  • Integrated built-in audio preview player inside the transcript, introduced the .bws project format with background AutoSave and crash recovery, and added the Track Selection drawer.

v3.1.1 & v3.1.0 - Standalone Analysis & Side-by-Side Diff

2026-06-21 - 2026-06-24
  • Introduced script-free Standalone Analysis to detect stutters/retakes automatically, Side-by-Side script comparison view, and Dynamic Programming diffing.
  • Added Technical Hotwords scraping from scripts into Whisper prompts and fixed Apple M4 initialization.

v3.0.0 - v3.0.5 - PySide6 GUI Rewrite

2026-05-03 - 2026-06-09
  • Complete UI migration from tkinter to PySide6 with custom frameless titlebar, dockable panels, Ctrl+F search widget, JSON settings, and 10 UI languages.
  • Added Fast Silence ("Simple Silence") workspace, Windows 11/macOS setup refinements, and audio-only timeline assembly fixes.

v2.0.0 - v2.0.3 - Windows Support & Faster-Whisper Migration

2026-02-01 - 2026-02-28
  • First Windows installer release alongside Linux/macOS, switching from openai-whisper to faster-whisper for dramatic RAM and speed improvements.
  • Added compute type selection (float16/int8), Lazy-Assemble background generation, RTL language support, and percentage progress tracking.

v1.0.0 - v1.0.3 - Initial Open-Source Release

2026-01-05 - 2026-01-20
  • First local proof-of-concept for DaVinci Resolve rough cutting with PDF/DOCX script import and modular algorithms.py / engine.py split.

Free, 100% local open-source AI rough cut studio for DaVinci Resolve, Premiere Pro, and Final Cut Pro.
