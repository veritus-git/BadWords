Release Notes

BadWords Changelog

Version history for BadWords v4. Full commit details are always public on GitHub Releases.

v4.1.2 - macOS UX, Resolve Bridge & Search

2026-11-26
  • macOS Window & Fullscreen Polish: Opens cleanly maximized to the desktop on first launch, closes Settings cleanly from Fullscreen Spaces without black flashes or ghost frames, and keeps popups smoothly draggable on Retina displays.
  • DaVinci Resolve Bridge & .bws Import: Read-only Lua timeline queries never switch your active timeline, Native and Bridge timeline fingerprints now match 1:1, and .bws exports bundle FCPXML fallback for Resolve Free 21.1+.
  • Live Chunked Manual Marks: Manual color markings made while words stream in are preserved when transcription finishes.
  • Faster Search & Auto-Updater Fixes: Precompiled Ctrl+F transcript search, faster Settings search, fixed in-app Update button, and opt-in Bridge/updater crash reporting.

v4.1.1 - Windows 11 Hardening & Transactional Updates

2026-11-25
  • Windows 11 Dark Surfaces & Safe Boot: Eliminated white taskbar preview rings and startup bars, added automatic BADWORDS_SAFE_BOOT=1 fallback on GPU-less PCs, and deferred Resolve DLL loading until Resolve is active.
  • Windows Whisper Symlink & Model Integrity Fix: Avoids unprivileged WinError 1314 and verifies partial model caches before loading.
  • Transactional Installer Updates: Existing files are replaced only after a valid release package downloads and extracts cleanly.

v4.1.0 - Unified Scaling, Zero-Sudo Setup & 11 Languages

2026-11-25
  • Unified Cross-Platform UI Scaling (75%-200%): True Auto OS DPI mode without double-scaling across Windows 11, Linux Wayland/X11, and macOS Retina.
  • Zero-Sudo Portable Python 3.12 & Static CRT: Removed root password prompts on Linux/macOS and eliminated missing VCRUNTIME140.dll errors on fresh Windows 11 installs.
  • Redesigned 9-Tab Settings & 11-Language Parity: Added live debounced Settings search, vector SVG icons across all themes, and synced 631 translation keys across all 11 languages.
  • Playback End Guard & Proxy Audio: Clean end-of-timeline playback stop and audio muxing into 360p Resolve video proxies.

v4.0.0 - Standalone Workstation & Live Waveform

2026-11-06
  • Launched full Standalone Mode (no Resolve required) with FCP7 XML, FCPXML, OTIO, and EDL export.
  • Added interactive waveform timeline with real-time cut skipping, sub-5 ms RAM silence sliders, Apple Silicon MLX acceleration (~11x), marquee box selection, and Rust GUI installer.
