Linux (Any Distro - Wayland & X11)

Install BadWords on Linux

Paste the command below into your terminal. Works on Ubuntu, Fedora, Arch, Debian, and immutable distros with zero sudo required.

Switch to Windows Switch to macOS Linux

Step 1 - Launch Setup

Paste into your Linux terminal

Terminal (bash) - Zero sudo, Portable CPython 3.12 View script source
$ curl -fsSL "https://badwords.dev/raw/linux" | bash

Step 2 - Inside the Setup Window

Pick option 1 to install

Inside the Setup GUI (or Terminal fallback if your system blocks GUI execution), you get 5 tools:

  • 1 - Fresh Install / Update Pick this first! Installs BadWords, portable Python 3.12, FFmpeg, desktop shortcut, and ~/.local/bin/badwords.
  • 2 - Repair Verifies ABI imports and restores missing dependencies without losing models or saves.
  • 3 - Move Relocates the installation folder cleanly.
  • 4 - Reset / 5 - Uninstall Wipes cleanly or removes BadWords and shortcuts.

Manual Binary Download

Download badwords-setup-linux from GitHub Releases and run: 

chmod +x badwords-setup-linux && ./badwords-setup-linux

Wayland, X11 & Portable Python

Uses relocatable CPython 3.12 in ~/.local/share/BadWords-runtime/python312 without touching system packages, supports native Wayland/X11 DPI scaling, and works even without GCC installed.
