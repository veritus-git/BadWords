macOS (Apple Silicon M1-M5 & Intel)

Install BadWords on macOS

Open Terminal (Cmd + Space -> Terminal), paste the command below, and press Enter. Zero sudo or Homebrew needed.

Step 1 - Paste into Terminal (zsh / bash) View script source
$ curl -fsSL "https://badwords.dev/raw/mac" | bash

Automatically installs portable Python 3.12, native Apple Silicon MLX (mlx-whisper, up to ~11x faster than CPU), FFmpeg, and Resolve script paths (standard & Mac App Store containers).

Gatekeeper & Manual Binary

Unsigned Universal Setup

If macOS Gatekeeper flags the unsigned GUI binary, the script opens Terminal Setup automatically. For manual downloads from GitHub Releases: 

xattr -d com.apple.quarantine badwords-setup-macos && chmod +x badwords-setup-macos && ./badwords-setup-macos

Step 2 - Inside the Setup Window

Pick option 1 to install

All 5 maintenance tools live in the same wizard so you can update or repair anytime using the same command:

1
Fresh Install / Update Pick this first
Deploys BadWords, portable Python 3.12, MLX/Whisper, FFmpeg, and DaVinci Resolve scripts cleanly.
2
Repair Installation
Verifies dependencies and fixes missing files without deleting models or project saves.
3
Move Installation
Relocates your BadWords directory cleanly to a different folder or drive.
4
Reset / 5. Uninstall
Option 4 wipes app caches and starts clean; option 5 removes BadWords completely.
