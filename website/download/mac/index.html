macOS (Apple Silicon M1-M5 & Intel)

Install BadWords on macOS

Open Terminal (Cmd + Space -> Terminal), paste the command below, and press Enter. Zero sudo or Homebrew required.

Windows macOS Linux
View script source
Terminal (zsh / bash) Native Apple MLX + Portable Python 3.12
$ curl -fsSL "https://badwords.dev/raw/mac" | bash

Manual Binary & Gatekeeper

If downloading badwords-setup-macos manually from GitHub Releases, strip the quarantine flag in Terminal first: 

xattr -d com.apple.quarantine badwords-setup-macos && chmod +x badwords-setup-macos && ./badwords-setup-macos

Apple Silicon MLX & Resolve App Store

On M1-M5 Macs, BadWords uses Apple's native Metal GPU engine (mlx-whisper) up to ~11x faster than CPU. It also auto-detects both standard and Mac App Store DaVinci Resolve script containers.
