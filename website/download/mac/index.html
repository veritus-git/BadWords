macOS (Apple Silicon M1-M5 & Intel)

Download BadWords for macOS

Free MIT open source with native Apple Silicon MLX acceleration (up to ~11x faster than CPU). Zero sudo or Homebrew required.

Download macOS Installer

v4.1.2 - 6.1 MB (Universal) - Requires ~4 GB app + AI model

1
Run the installer
If macOS warns about unsigned apps, use the 1-line Terminal command below (skips Gatekeeper cleanly), or allow badwords-setup-macos via xattr -d com.apple.quarantine first.
2
Choose option 1 (Fresh Install / Update)
Deploys BadWords, portable Python 3.12, MLX/Whisper, FFmpeg, and DaVinci Resolve scripts (both standard and Mac App Store). Options 2-5 Repair, Move, Reset, or Uninstall anytime later.
3
Open BadWords from Applications
Drop video files directly or link DaVinci Resolve in seconds.

Easiest 1-line Terminal install (Cmd + Space -> Terminal, handles Gatekeeper automatically):

$ curl -fsSL "https://badwords.dev/raw/mac" | bash
