macOS (Apple Silicon & Intel)

Download BadWords for macOS

Choose whichever method you prefer below - zero sudo or Homebrew required, with native Apple Silicon MLX acceleration (~11x faster than CPU).

Option A - Terminal

View script source

One-line terminal install

Open Terminal (Cmd + Space -> Terminal) and paste this command. Handles unsigned binary Gatekeeper warnings automatically.

$ curl -fsSL "https://badwords.dev/raw/mac" | bash

Option B - Direct File

v4.1.2 - 6.1 MB Universal

Download standalone installer

Download badwords-setup-macos directly. If Gatekeeper flags the unsigned binary, clear quarantine with xattr -d com.apple.quarantine badwords-setup-macos and run it.

Download badwords-setup-macos

How Installation Works

Pick option 1 in the setup window

  1. 01.Start BadWords Setup

    Run either the Terminal command or the downloaded binary. Both open the setup window shown on the right.

  2. 02.Choose option 1 (Fresh Install / Update)

    Installs BadWords, portable Python 3.12, MLX/Whisper, FFmpeg, and DaVinci Resolve scripts (both standard and Mac App Store containers). Options 2-5 Repair, Move, Reset, or Uninstall anytime later.

  3. 03.Launch BadWords

    Open BadWords from Applications (~4 GB app + 1-5 GB local AI model). Drop local files directly or link DaVinci Resolve in seconds.
