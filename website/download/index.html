One unified Rust GUI installer across Windows, macOS, and Linux. Installs to your user directory with zero admin or sudo privileges needed (~4 GB app + 1-5 GB AI models).

What the installer sets up for you

  • Isolated Python 3.12 runtime (portable, never touches your system Python) + FFmpeg + CUDA/MLX libraries.
  • Automatic DaVinci Resolve scripts and BadWords Bridge Lua setup if Resolve is installed.
  • 5 built-in maintenance modes: Fresh Install/Update, Repair, Move, Reset, and clean Uninstall.
Security Notice - Smart App Control & Gatekeeper

Because BadWords is free open-source software without a $400/yr code-signing certificate, Windows Smart App Control or macOS Gatekeeper may flag the GUI binary. If blocked, the bootstrap script automatically offers the identical Terminal Installer fallback.

Hardware & Compatibility

Windows 10 / 11 (64-bit)

NVIDIA GPU with driver 525+ recommended for CUDA acceleration; automatic safe CPU fallback on laptops/school PCs without dedicated GPUs.

macOS (Apple Silicon & Intel)

Native Metal acceleration via mlx-whisper on M1-M5 Macs (up to ~11x faster than CPU), plus full Intel Mac support.

Linux (Wayland & X11)

Works on any modern distro (Ubuntu, Fedora, Arch, Debian) with zero sudo required using portable CPython 3.12.
