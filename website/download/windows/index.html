Manual Binary Download

Download badwords-setup-windows.exe from GitHub Releases. If Windows SmartScreen blocks it: right-click the file -> Properties -> check Unblock -> Apply.

GPU & Clean-PC Notes

Supports NVIDIA CUDA (driver 525+) automatically, and safely falls back to CPU on non-NVIDIA or older PCs. Automatic VC++ Runtime check and Windows 11 Smart App Control fallback are built in.
