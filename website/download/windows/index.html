Windows 10 & 11 (64-bit)

Download BadWords for Windows

Free MIT open source - installs cleanly into your user folder without Administrator permissions. Supports NVIDIA CUDA GPUs and standard CPU PCs.

Download Windows Installer (.exe)

v4.1.2 - 10.5 MB (.exe) - Requires ~4 GB app + AI model

1
Run the downloaded file
Double-click badwords-setup-windows.exe to open the BadWords Setup window (shown on the right).
2
Choose option 1 (Fresh Install / Update)
It automatically downloads BadWords, FFmpeg, Whisper, and links DaVinci Resolve. You can use the same file later to Repair (2), Move (3), Reset (4), or Uninstall (5).
3
Launch BadWords from Desktop or Start Menu
NVIDIA driver 525+ uses CUDA automatically; laptops without NVIDIA GPUs switch cleanly to CPU mode.

Windows Smart App Control warning? Because BadWords is free without a $400/yr certificate, paste this line into PowerShell instead for the identical setup:

PS> irm "https://badwords.dev/raw/windows" | iex
