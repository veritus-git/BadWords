Local-First Architecture

Privacy Policy

BadWords is open-source software designed so your raw media, dialogue, and scripts stay strictly on your own machine.

1. Zero Cloud Media Processing

Audio extraction, AI speech recognition (Faster-Whisper / Apple MLX), script comparison, silence analysis, and XML/OTIO/EDL generation all run 100% locally. BadWords never uploads your audio, video, transcripts, project files, or scripts to any server.

2. Optional Anonymous Telemetry

When explicitly enabled by you in the first-run consent prompt (or Settings -> About & Privacy), BadWords sends a minimal anonymous ping containing only an anonymous hashed machine ID, OS type, app version, and optional coarse region (if enabled). You can disable this completely at any time.

3. Optional Automatic Crash Reports

Crash reporting is controlled by a separate user consent setting stored locally in user.json. Before any crash report is sent, BadWords automatically scrubs usernames, home folder paths, and environment secrets, and rate-limits submissions to prevent spam.

4. Website (badwords.dev)

badwords.dev is a static website with zero ad trackers, zero third-party marketing cookies, and zero account logins. Source code is auditable anytime on GitHub.
